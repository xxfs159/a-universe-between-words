# 一句话的宇宙
除本行外所有工作皆由GPT与Claude完成，共计4min18s

一段 1 分 56 秒的网页动画。所有视觉和配乐都由代码实时生成，单个 HTML 文件包含全部样式、着色器、场景和音频合成逻辑。

**[在线体验](https://xxfs159.github.io/a-universe-between-words/)**

## 打开

用现代 Chrome、Edge、Firefox 或 Safari 打开 `index.html`，点击「进入动画」。声音需要这次点击才能启动。无需安装依赖，也无需联网。

## 七章

抵达 → 文本片段 → 数值表示 → 上下文关联 → 多层变换 → 逐步生成 → 回应。

这是一部概念短片。星云、粒子、节点、层数和概率都是艺术化示意；字符切分不是实际 tokenizer，结尾文字是预先编排的，不是实时 AI 回答。

## 操作

- 空格：播放 / 暂停
- 左右方向键：前后跳转 5 秒
- M：声音开关
- H：沉浸模式，轻触空白画面也可恢复
- F：全屏
- 时间线：拖动定位
- 右侧圆点：七章跳转
- 「你的消息」：更换开场文本（本地处理）
- 「高画质 / 流畅」：10,000 / 4,500 粒子与分辨率切换；帧率较低时自动切换为流畅
- 「创作手记」：解释视觉比喻与技术

## 纯代码技术

WebGL 程序星云（分形布朗噪声、域扭曲）、三维投影、粒子形态插值、文字栅格采样、加法混合光晕、景深风格光点、程序颗粒、视差、空间螺旋、球体经纬线、动态贝塞尔光路、计算层光环、生成分支、逐字排版。

Web Audio 合成和弦、双振荡器微失谐、FM 音色、琶音、低音与脉冲鼓、带通噪声扫频、程序生成的立体声混响脉冲、反馈延迟、动态压缩、FFT 频谱与光晕联动。没有加载任何音频、图片、字体、视频或第三方脚本。

WebGL 不可用时，自动使用 Canvas 粒子兼容模式。全屏受浏览器容器权限影响；若内嵌预览不支持全屏，请直接在浏览器打开 HTML。
